# Live lessons -> tests (PRD-HPC-1461 AC-11)

Every live-run lesson of the old in-pod waiter (`kubecore/meluxina.py` in hera-pipeline-template before F-35)
has a test in this repo. This table is the checklist; a lesson that has no test is a gap to close, not a
note. Tests that came from a live incident carry the live job id in their name or docstring
(`grep -rn "live_job_\|live job" runner/tests internal`).

Test locations: **R** = `runner/tests/<file>`, **G** = Go under `internal/`. Names are shortened; the live
incident tests added for AC-11 are in `runner/tests/test_live_lessons.py` and
`internal/runnerjob/livelessons_test.go`.

Audit date 2026-11-08 (rows 27-31 and the gaps in rows 15, 21, 22 closed by the PR that added this file).
Rows 15 and 21 note one boundary: the stager that evicts unused dataset copies after 24 h is not part of this
repo; here the contract it relies on (the lease word in the job comment, the `.kaos-used` marker) is tested.
